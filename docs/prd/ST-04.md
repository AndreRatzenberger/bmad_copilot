## User Story
As an Analyst I want suggestions when theory evidence is sparse so that I can refine my inquiry.

## Acceptance Criteria
- Trigger threshold: (supports + contradicts) < 3
- Provide ≥ 2 related_suggestions strings

## Notes
Leverages embedding nearest tags or phrase expansion.

## UI Implementation Notes (2025-09-22)
