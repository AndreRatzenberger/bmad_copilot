## User Story
As a Research Engineer I want to search papers and repos together so that I avoid switching tools.

## Acceptance Criteria
- /search supports `types=[paper,repo]` filter (default both)
- Ranking uses composite formula (initial simple cosine + tag overlap allowed)
- Each result includes entity type badge
- Empty state provides guidance

## Notes
Requires embeddings + similarity implementation (basic baseline allowed first).
