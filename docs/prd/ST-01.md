## User Story
As a Research Engineer I want to see the latest enriched papers so that I can quickly triage relevance.

## Acceptance Criteria (Initial)
- List endpoint returns latest N papers sorted by published/ingested date
- Each item shows: title, summary snippet, scores (relevance, interesting), tags
- Pagination (page/page_size) available
- Response time median < 300 ms (corpus < 5K)

## Notes
Depends on ingestion + enrichment pipeline delivering enriched records.
