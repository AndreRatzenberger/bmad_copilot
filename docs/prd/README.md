# PRD Story Shards

This directory contains sharded user stories derived from `../prd.md` (v0.1 Draft).

Each story file tracks implementation status independently and is the handoff unit for the Scrum Master → Dev cycle.

Status Legend:
- Draft: Extracted, needs PO/SM refinement
- Ready: Approved for development
- In Progress: Being implemented
- Review: Awaiting QA / PO review
- Done: Accepted

See individual `ST-XX.md` files for details.
