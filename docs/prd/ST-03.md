## User Story
As an Analyst I want to input a theory and view supporting & contradicting evidence so that I can evaluate the idea.

## Acceptance Criteria (From PRD)
GIVEN a theory string ≥ 10 chars WHEN submitted THEN JSON includes `supports[]`, `contradicts[]`, optional `related_suggestions[]`.
If total evidence < 3 suggestions length ≥ 2.
Evidence item fields: id, title, summary_snippet, confidence (low|medium|high).
